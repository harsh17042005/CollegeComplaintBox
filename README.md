# 🎓 College Complaint Box

A web application that allows college students to submit complaints easily.

## Features
- Submit complaints using a form
- Select complaint categories
- Enter complaint descriptions
- Option to submit anonymously
- Basic input validation

## Technologies Used
- Python
- Streamlit
- MongoDB (planned integration)

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   streamlit run app.py
   ```

## Project Status
The basic complaint submission interface is ready. MongoDB integration is planned for a future update.
